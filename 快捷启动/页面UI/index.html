推荐首次顺序

  1. 第一次换电脑先双击 快捷启动脚本/准备运行环境.cmd。
  2. 再双击 快捷启动脚本/启动控制台.cmd。
  3. 运行“首次配置检查”，按提示补 `.env`、候选人画像、飞书群。
  4. 分别打开 BOSS / 猎聘登录窗口，人工扫码或验证。
  5. 先跑草稿测试，再开启采集、推送和定时。

文件管理器按钮说明

页面里有两类按钮：蓝色/灰色按钮是普通链接，浏览器可以自己打开；青色“文件管理器打开...”按钮需要本地 helper，才能调起 Windows 文件管理器。

如果你是直接双击 index.html 打开的页面，普通链接可能能跳，但文件管理器按钮会失败。请改为双击 快捷启动\快捷启动脚本\启动控制台.cmd，它会打开页面并启动 helper。

页面里的路径/命令怎么理解？

本页面会根据当前 index.html 的真实位置反推分享包根目录。你现在看到的盘符和目录来自当前安装位置，不是写死值；把分享包挪到 E 盘或其他文件夹后，重新打开页面会显示新位置。

分享包根目录：正在识别...

页面中的复制命令已经是完整一行命令：会先进入分享包根目录，再执行对应脚本；可直接粘贴到 CMD 或 PowerShell，不依赖当前终端目录。

如果你只是想打开文件夹，请不要把命令粘贴到文件管理器地址栏。请点击青色“文件管理器打开...”按钮，或在文件管理器里直接双击 快捷启动\快捷启动脚本 下的 `.cmd` 文件。
