# 安装与依赖说明

## 1. 必需依赖

| 依赖 | Windows | macOS | 用途 |
| --- | --- | --- | --- |
| Node.js >= 22.5 | 官网安装包或随包 Node | Homebrew / 官网 | 运行本地服务与 `node:sqlite` |
| npm | 随 Node | 随 Node | 安装 Electron |
| Google Chrome | `C:\Program Files\Google\Chrome\Application\chrome.exe` | `/Applications/Google Chrome.app` | BOSS/猎聘登录与采集 |
| Electron 28 | `npm install` | `npm install` | 桌面窗口/托盘 |
| 飞书 SDK（可选） | 消息平台 vendor | 同左 | 原消息平台长连接 |

## 2. Windows 启动

1. 安装 Node.js 22.5+ 和 Chrome；
2. 双击根目录 `启动招聘智能体.cmd`；
3. 首次会自动 `npm install` 并写入演示数据；
4. 如果 Electron 起不来，会自动打开浏览器页面。

## 3. macOS 启动

```bash
cd 招聘智能体/recruitment-agent
npm install
npm run doctor
npm run v14:seed-demo   # 可选
npm run electron
```

也可以双击根目录 `启动招聘智能体.command`。  
如果系统提示没有执行权限：

```bash
chmod +x 启动招聘智能体.command
```

macOS 首次打开可能需要在“系统设置 → 隐私与安全性”允许。

## 4. 依赖检查

```powershell
cd 招聘智能体\recruitment-agent
npm run doctor
```

会检查：

- 操作系统（win32/darwin）；
- Node.js 版本；
- Chrome 路径；
- Electron 是否安装；
- 消息平台目录；
- 飞书 SDK 是否安装。

## 5. 消息平台（原飞书机器人）

原消息平台是独立服务，目录：

```text
消息平台/message-platform
```

在客户端“消息”页填写：

- App ID；
- App Secret；
- 群 ID（Chat ID）；
- Verification Token；
- Encrypt Key（可选）。

保存后会写入 `消息平台/message-platform/.env`，并同步启用 `channels.config.json` / `routes.config.json` 中的群 ID。

启动服务：

```powershell
cd 消息平台\message-platform
node src/cli/start_feishu_long_connection.js
```

或在客户端“消息”页点“启动消息平台”。

如果提示缺少 `@larksuiteoapi/node-sdk`，需要先安装该依赖：

```powershell
cd 消息平台\message-platform
npm install @larksuiteoapi/node-sdk
```

> 消息平台需要飞书自建应用权限、事件订阅、机器人入群；未配置成功前不要开启真实渠道。

## 6. 打包

```powershell
cd 招聘智能体\recruitment-agent
npm run build:win   # Windows NSIS
npm run build:mac   # macOS DMG（需在 Mac 上执行）
```

安装包不包含 Chrome；目标电脑需安装 Chrome。

## 7. 常见问题

- **启动器没窗口**：运行 `npm run doctor`；检查 Chrome/Electron；运行 `npm run v14:serve` 看端口。
- **端口占用**：关闭旧 Node/Electron 进程，或设置 `V14_PORT`。
- **macOS 提示未签名**：开发包可在“隐私与安全性”允许；正式分发需要 Apple 签名/公证。
- **消息平台启动失败**：查看客户端“消息”页日志，或 `消息平台/message-platform/logs/service.log`。
