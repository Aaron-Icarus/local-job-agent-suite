# 安装包构建与发布

## Windows 便携版（当前可立即使用）

生成文件：

```text
招聘智能体/recruitment-agent/release/招聘智能体-1.5.2-portable.zip
```

ZIP 顶层只有：

```text
招聘智能体\
安装招聘智能体.cmd
安装招聘智能体.ps1
使用说明.txt
```

- 解压后不会再把 Electron 文件铺满目标盘；
- 直接运行 `招聘智能体\招聘智能体.exe` 即可；
- 或双击 `安装招聘智能体.cmd`，选择目录，复制到目标目录并创建桌面/开始菜单快捷方式；
- 安装脚本使用 PowerShell 复制，不需要管理员权限，也不会创建 `.installer-temp`。

> 当前机器上单文件 EXE 安装器的进程被 Windows 安全机制限制，无法在目标目录创建子目录；便携版的 PowerShell 安装方式已验证可以写入 D/E 盘。

## Windows 单文件安装包

当前已生成：

```text
招聘智能体/recruitment-agent/release/招聘智能体-1.5.2-x64-setup.exe
```

安装流程：

1. 双击安装包；
2. 在“选择安装文件夹”窗口选择目标目录；
3. 安装程序解压主程序、Node 运行时、消息平台和技能文件；
4. 自动创建桌面快捷方式和开始菜单快捷方式；
5. 完成后可勾选启动。

默认安装目录：

```text
%LOCALAPPDATA%\Programs\招聘智能体
```

安装后程序数据：

```text
<安装目录>\data\v1.4\jobs.db
<安装目录>\data\logs\
<安装目录>\message-platform\
```

如果单文件 EXE 报“访问被拒绝”，不要以管理员身份反复运行，改用上面的便携版 `安装招聘智能体.cmd`；这是当前 Windows 安全软件/进程权限导致的环境问题，不是系统未注册。

Windows 安装程序源码在 `scripts/installer/Installer.cs`，单文件 EXE 内嵌运行时与 7z 负载。

## macOS 安装包

macOS 需要 macOS 机器上的 `hdiutil` 和 Apple 工具链，Windows 上不能直接生成 DMG。

仓库已提供：

- `npm run build:mac`（electron-builder DMG）；
- `.github/workflows/build-installers.yml`（macOS runner 构建 DMG）；
- app 图标 `build/icon.png`；
- macOS 运行时按当前架构使用 Node 二进制。

在 GitHub Actions 手动执行 `Build Installers`，下载 `macos-installer` artifact 即 DMG。

## 安装后

- 打开应用后，后台服务自动启动；
- 数据在安装目录 `data`；
- Chrome 使用本机安装，首次需要登录 BOSS/猎聘；
- 程序运行期间任务执行器会读取：
  - `idle_minutes`：系统空闲阈值；
  - `cpu_max_percent` / `battery_min_percent`；
  - 采集时间段与最小间隔；
- 检测到 CPU 忙/电量低/未空闲时，采集任务会延后，不抢当前操作。

## 开发构建

```powershell
cd 招聘智能体\recruitment-agent
npm install
npm run prepare:runtime
npm run build:win
```

macOS：

```bash
cd 招聘智能体/recruitment-agent
npm install
npm run prepare:runtime
npm run build:mac
```

## 注意

- 安装包不包含真实飞书配置、API Key、简历、画像、mock 数据；
- 首次安装后需要在消息页重新填写飞书 App ID/Secret/群 ID；
- Windows 安装包未做代码签名，首次运行可能出现 SmartScreen 提示；正式发布建议购买签名证书；
- macOS 未签名时需要在“隐私与安全性”允许打开。
