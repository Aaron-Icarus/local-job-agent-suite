# 路径与便携性说明

## 1. 结论

项目默认使用**相对路径 + 运行目录内的数据目录**，整个项目文件夹移动到新电脑、换盘符、换用户名后可以继续运行。

仓库内没有依赖 `E:\...`、`D:\...`、`/Users/xxx` 这类项目绝对路径。  
可用：

```powershell
cd 招聘智能体\recruitment-agent
npm run path:audit
```

期望输出：

```json
{"ok": true, "findings": []}
```

## 2. 路径基准

| 起点 | 计算方式 |
| --- | --- |
| 项目根 | 根目录 `启动招聘智能体.cmd` / `.command` 所在目录 |
| 客户端目录 | `<项目根>/招聘智能体/recruitment-agent` |
| 数据目录 | `<客户端目录>/data` |
| 数据库 | `<客户端目录>/data/v1.4/jobs.db` |
| 日志 | `<客户端目录>/data/logs/` |
| 加密密钥 | `<客户端目录>/data/v1.4/secret.key` |
| Chrome Profile | 默认系统用户目录，可用 `V14_CHROME_PROFILE` 指到项目内 |
| 消息平台 | `<项目根>/消息平台/message-platform` |

启动脚本使用：

- `.cmd`：`%~dp0`
- `.ps1`：`$MyInvocation.MyCommand.Path`
- `.command`：`dirname "$0"`
- Electron：`__dirname`
- Node 服务：`__dirname` / `path.resolve(...)`

**不依赖 `process.cwd()` 作为项目根路径。**

## 3. 环境变量覆盖

| 变量 | 默认 | 说明 |
| --- | --- | --- |
| `V14_DB_PATH` | `data/v1.4/jobs.db` | 数据库位置 |
| `V14_LOG_DIR` | `data/logs` | 日志目录 |
| `V14_CHROME_PROFILE` | 系统用户目录 | Chrome 独立 Profile |
| `V14_CHROME_PATH` | 自动查找 | Chrome 可执行文件 |
| `V14_MESSAGE_PLATFORM_DIR` | `../../../../消息平台/message-platform` | 消息平台目录 |
| `V14_SECRET_KEY_PATH` | `data/v1.4/secret.key` | 加密密钥 |
| `V14_EXPORT_DIR` | 用户下载目录 | Excel 导出位置 |
| `V14_NODE` | 系统 Node | Electron 启动后台服务用 |
| `V14_PORT` | 4780 | 本地服务端口 |

## 4. 系统相关路径

这些是操作系统路径，不是项目绝对路径：

- Windows Chrome：
  - `C:\Program Files\Google\Chrome\Application\chrome.exe`
  - `C:\Program Files (x86)\...`
- macOS Chrome：
  - `/Applications/Google Chrome.app/...`
- Electron 启动日志：
  - Windows：`%APPDATA%\boss-job-agent\startup.log`
  - macOS：`~/Library/Application Support/...` 兼容逻辑

Chrome 安装路径是自动探测的，不把项目绑定到某台电脑。

## 5. 迁移到新电脑

1. 复制整个项目根目录；
2. 安装 Node.js 22.5+ 和 Chrome；
3. 运行：

```powershell
cd 招聘智能体\recruitment-agent
npm install
npm run doctor
npm run path:audit
```

4. 双击 `启动招聘智能体.cmd` 或 `启动招聘智能体.command`；
5. 如果消息平台单独移动，设置 `V14_MESSAGE_PLATFORM_DIR`。

数据库、日志、密钥都在项目 `data` 下，随项目一起复制即可；`.env` 中的飞书凭证需要在新电脑重新填写。

## 6. 已知例外

- `src/greeting/build_candidate_profile.js`、`job_greeting_agent.js` 和消息平台 `send_notification.js` 对**用户传入的 CLI 文件参数**使用 `process.cwd()`，这是命令行工具的常规语义；用户传绝对路径也支持。
- Chrome 安装路径和用户下载目录是系统级路径，不是项目路径。
- `data/logs`、`data/v1.4`、`.env` 已在 `.gitignore` 中，不会随仓库上传。
