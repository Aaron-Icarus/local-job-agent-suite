## 处理建议

1. 继续只提交代码、测试、文档和示例配置；真实群配置保持在本地。
2. `.env`、`data/`、`outputs/`、`resumes/`、日志永远不要提交。
3. 如果曾经把真实群 ID / Secret 推到公开仓库，除了删除文件，还要在飞书后台轮换 Secret。
4. 新功能分支提交前运行一次敏感扫描，确认工作区真实配置文件没有被 `git add -A` 带入。
