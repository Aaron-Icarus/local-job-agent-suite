## 3. 行为约定

### 3.1 Chrome / CDP

- 默认端口 9222；
- 端口被占用（包括被绑定但未监听）自动切换 9223-9322；
- 端口写入 `data/cdp.json`，并注入 `CDP_PORT`；
- 状态可查：`GET /api/chrome/status`；
- 启动 Chrome 默认 `--start-minimized`；
- 登录检查只关闭 `login_boss` / `login_liepin` 专用标签，不动采集标签和用户标签。

### 3.2 登录检查

- `POST /api/login/check` 自动启动/复用 Chrome；
- 已登录：HTTP 200，前端显示本地时间；
- 未登录：HTTP 401；
- 安全验证/无法确认：HTTP 409；
- 检测成功且 Chrome 是本次启动时，自动关闭检测 Chrome；失败时保留登录页供人工处理。

### 3.3 任务

- 主区域：待处理任务和进行中采集事件；
- 下方窗口：历史任务/历史事件，内部滚动；
- 采集任务会实际调用采集脚本，并传入角色关键词；
- 自动采集受电脑空闲状态控制；手动“立即执行/手动生成”不受空闲限制；
- `score` 任务当前会明确失败（执行器尚未接入 v14 评分），不会静默排队。

### 3.4 飞书群与路由

- 群管理：只做添加、测试、重命名、删除；
- 群状态：正常 / 异常 / 未测试 / 停用，异常和停用排在前面；
- 删除群：二次确认，显示群信息和正在使用该群的角色；
- 默认通知群：独立选择 + 保存；
- 角色路由：每角色一行，登录状态/操作异常/每日日报三列下拉，右上角统一保存；
- 未点保存前切换页面，回来仍显示已保存配置；
- 应用配置：App ID/Secret、长连接启动/停止、Webhook；不负责群增删和角色路由。

### 3.5 通知历史

- `GET /api/notifications?q=&from=&to=&page=1&page_size=10`；
- 标题/正文/类型关键词搜索；
- 开始/结束日期筛选；
- 每页 10/20/50；
- 内部滚动，点击查看详情。
