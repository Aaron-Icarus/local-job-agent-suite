# 招聘智能体 Skill 使用说明

这里放的是本软件的本地 Skill 入口文件，供其他智能体阅读“怎么使用本软件”，不包含软件内部实现细节。

## 文件说明

- `resume_profile_skill.md`：如何从简历生成角色画像，包含字段、隐私和输出格式。
- `daily_keyword_skill.md`：如何生成每日搜索关键词、推荐词/兜底词和轮换规则。
- `usage_skill.md`：软件整体操作顺序、配置 AI/飞书群/角色、输出物校验。

## 给其他智能体怎么问

可以把整个文件夹路径或单个文件交给其他智能体，然后问：

```text
请阅读这些 Skill，按里面的格式帮我生成角色画像/关键词/操作步骤。
不要编造经历；缺失信息先问我。
输出前按 Skill 里的校验清单检查。
```

## 路径

本机路径可在客户端“对话”页右上角“Skill 目录”中一键打开并显示。

## 输出校验

所有输出必须检查：

- 画像不写电话、邮箱、密码、身份证、微信、QQ；
- 画像不写“每日搜索关键词”列表；
- 技能关键词、求职偏好/避雷、兜底关键词允许写；
- 每日关键词是独立数组，推荐 8-12 个、兜底 3-5 个；
- 城市/薪资是筛选条件，不混入搜索关键词；
- 不确定的信息写“需确认”，不能编造。
