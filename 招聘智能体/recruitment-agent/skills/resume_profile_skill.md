# 角色画像生成 Skill（本地）

## 目标

把用户上传的简历、目标岗位、城市、薪资、经历，整理成一份可用于“角色”的本地画像 Markdown。

## 必须收集的信息

1. 简历原文（Markdown / 文本）；
2. 目标岗位（一个或多个）；
3. 目标城市；
4. 目标薪资区间（K）；
5. 相关经历（可来自简历）。

## 画像必须包含的结构

1. `# 姓名 / 角色画像`
2. `## 基础信息`：姓名、学历、专业、目标岗位、目标城市、薪资预期；
3. `## 求职诉求`：用户想要什么岗位、城市、薪资、方向、偏好和限制；
4. `## 职业发展期望`：行业方向、目标岗位、城市、薪资、希望做的事情；
5. `## 工作经历`：按时间倒序，保留公司、岗位、项目、金额、团队规模、成果；
6. `## 能力标签`：从经历提炼，不要只抄简历；
7. `## 技能关键词`：人物技能标签，可以写；
8. `## 求职偏好/避雷`：用自然语言描述“想要什么、不想要什么”，不要求关键词列表；
9. `## 兜底关键词`：默认搜索兜底词，可人工调整；
10. `## 风险/需确认`：简历缺失或需要用户确认的信息。

**画像 MD 中不要写：**

- 电话、手机号、邮箱、密码、身份证、微信、QQ、联系方式；
- “每日搜索关键词”（下一轮搜索用词，单独模块生成）；
- 搜索用关键词列表。

技能关键词、求职偏好/避雷（描述）、兜底关键词可以写进画像。

每日搜索关键词由 `skills/daily_keyword_skill.md` 单独生成，并保存到角色的 `role_keywords`，不进入画像的“每日搜索关键词”。

## 隐私规则

- 简历中的电话号码、邮箱、密码、验证码、身份证号、微信号、QQ 号不写入画像；
- 如果 AI 生成内容包含上述信息，必须删除；
- 只保留与求职匹配相关的经历、能力、目标和期望；
- 画像用于本地角色，不得上传到公开仓库或外部服务。

## 规则

- 只使用用户提供的真实信息，不虚构公司、项目、学历、证书、薪资。
- 缺信息时先问，不要直接编造。
- 画像生成后，作为角色创建时的 `profile_md`；原始简历保存到 `resumes` 表。
- 如果用户问“有什么岗位”，调用本地岗位库按角色评分搜索，输出岗位编号、公司、岗位、评分。
- 如果用户要求“生成角色”，先确认画像信息完整，再给出画像；是否创建角色由用户确认。

## ReAct 工具

- `parse_resume`：解析上传的 Markdown 简历；
- `ask_missing`：缺字段时向用户提问；
- `generate_profile`：信息完整时生成画像 Markdown；
- `generate_keywords`：单独生成每日搜索关键词（不写进画像）；
- `search_jobs`：按当前角色查询岗位库，返回岗位编号和基本信息。
