# 角色画像生成 Skill（本地）

## 目标

把用户上传的简历、目标岗位、城市、薪资、经历，整理成一份可用于“角色”的本地画像 Markdown。

## 必须收集的信息

1. 简历原文（Markdown / 文本）；
2. 目标岗位（一个或多个）；
3. 目标城市；
4. 目标薪资区间（K）；
5. 相关经历（可来自简历）。

## 画像必须包含的结构

1. `# 姓名 / 角色画像`
2. `## 基础信息`：姓名、学历、专业、目标岗位、目标城市、薪资预期；
3. `## 职业发展期望`：行业方向、目标岗位、城市、薪资、希望做的事情；
4. `## 工作经历`：按时间倒序，保留公司、岗位、项目、金额、团队规模、成果；
5. `## 能力标签`：从经历提炼，不要只抄简历；
6. `## 技能关键词`：AI/技术/业务关键词，供搜索使用；
7. `## 每日搜索关键词`：8–12 个，按“岗位名 + 行业/技术方向 + 同义词”组合；
8. `## 搜索排除词`：明显不匹配的方向；
9. `## 风险/需确认`：简历缺失或需要用户确认的信息。

## 每日关键词生成规则

- 从目标岗位拆出主关键词（如 AI项目经理、AI产品经理、智能体交付）；
- 从经历拆出技术/业务关键词（如 AI Agent、LLM、RAG、私有化部署、MCP、VibeCoding、数据治理、UAT）；
- 组合派生词：`AI项目经理`、`AI项目交付`、`AI产品经理`、`智能体项目经理`、`大模型应用交付`；
- 城市/薪资单独作为筛选条件，不写进关键词；
- 排除过宽词（如“项目经理”单独使用）和明显不相关方向；
- 关键词用于每日采集/搜索，后续可按结果反馈调整。

## 规则

- 只使用用户提供的真实信息，不虚构公司、项目、学历、证书、薪资。
- 缺信息时先问，不要直接编造。
- 画像输出必须包含：目标岗位、目标城市、薪资预期、技能、经历摘要、避雷/偏好（如有）。
- 画像生成后，作为角色创建时的 `profile_md`；原始简历保存到 `resumes` 表。
- 如果用户问“有什么岗位”，调用本地岗位库按角色评分搜索，输出岗位编号、公司、岗位、评分。
- 如果用户要求“生成角色”，先确认画像信息完整，再给出画像；是否创建角色由用户确认。

## ReAct 工具

- `parse_resume`：解析上传的 Markdown 简历；
- `ask_missing`：缺字段时向用户提问；
- `generate_profile`：信息完整时生成画像 Markdown；
- `search_jobs`：按当前角色查询岗位库，返回岗位编号和基本信息。
