# 角色画像生成 Skill（本地）

## 目标

把用户上传的简历、目标岗位、城市、薪资、经历，整理成一份可用于“角色”的本地画像 Markdown。

## 必须收集的信息

1. 简历原文（Markdown / 文本）；
2. 目标岗位（一个或多个）；
3. 目标城市；
4. 目标薪资区间（K）；
5. 相关经历（可来自简历）。

## 规则

- 只使用用户提供的真实信息，不虚构公司、项目、学历、证书、薪资。
- 缺信息时先问，不要直接编造。
- 画像输出必须包含：目标岗位、目标城市、薪资预期、技能、经历摘要、避雷/偏好（如有）。
- 画像生成后，作为角色创建时的 `profile_md`；原始简历保存到 `resumes` 表。
- 如果用户问“有什么岗位”，调用本地岗位库按角色评分搜索，输出岗位编号、公司、岗位、评分。
- 如果用户要求“生成角色”，先确认画像信息完整，再给出画像；是否创建角色由用户确认。

## ReAct 工具

- `parse_resume`：解析上传的 Markdown 简历；
- `ask_missing`：缺字段时向用户提问；
- `generate_profile`：信息完整时生成画像 Markdown；
- `search_jobs`：按当前角色查询岗位库，返回岗位编号和基本信息。
