# 软件使用 Skill

## 目标

只说明怎么使用本软件和输出物格式，不描述内部实现，避免把软件细节带走。

## 使用顺序

1. 配置 AI Provider：AI 能力 → 添加供应商 → 测试 → 启用。
2. 配置飞书应用：消息 → 飞书机器人应用 → 填 App ID/Secret → 保存 → 启动消息平台。
3. 注册飞书群：消息 → 飞书群管理 → 添加群（名称/Chat ID/Webhook）→ 测试。
4. 配置默认群和角色路由：默认通知群选群并保存；角色通知群每角色一行，点“一键配置”选择群，确认后填入三个环节，再点保存。
5. 创建角色：角色 → 填昵称、上传简历或粘贴简历/标准画像、目标岗位、城市、薪资、关键词 → 创建。创建后右侧先出现灰色“处理中”角色，AI 完成画像后按钮自动恢复；原文件在 `data/resumes/files/`，可用“原始简历”查看。
6. 检查登录：首页 → 检查登录；Chrome 会自动启动并在后台检测。
7. 采集：首页 → 手动生成采集任务 → 任务页查看待处理/历史。
8. 看结果：职位库详情先看清洗后 JD，可展开原始 JD；导出 Excel 会生成任务，到任务列表看完成情况和文件路径。
9. 日报：按角色生成，只推当天评分达到标准的合适岗位；每个角色单独记录。

## 角色画像输出格式

```text
# 姓名/角色画像
## 基础信息
## 求职诉求
## 职业发展期望
## 工作经历
## 能力标签
## 技能关键词
## 求职偏好/避雷
## 兜底关键词
## 风险/需确认
```

不要写：电话、邮箱、密码、身份证、微信、QQ、每日搜索关键词列表。

## 关键词输出格式

```json
{
  "recommended": ["8-12 个推荐词"],
  "fallback": ["3-5 个兜底词"],
  "manual": ["人工高优词，可手工添加"]
}
```

- 推荐词和兜底词不重复；
- 人工词优先采集，AI 不得覆盖；
- 城市、薪资、姓名不写进关键词；
- 结合用户意愿和历史效果轮换。

## 校验清单

- 画像字段齐全，且没有联系方式；
- 画像没有“每日搜索关键词”；
- 关键词数组长度正确，分隔符统一用“、”；
- 城市是“省-市-区/全部”，薪资是正整数千元区间；
- 角色创建前检查画像、关键词、渠道；
- 采集任务执行前确认登录状态和 Chrome CDP；
- 群路由保存后再测试通知。
