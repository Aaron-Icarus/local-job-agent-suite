# 每日日报 Skill（分角色版）

## 目标

每个角色单独生成日报。日报只推送**当天完成评分、且达到合适标准**的岗位，不是把当天所有已评分岗位全部发出去。

## 输入

- 角色画像、目标岗位、城市、薪资；
- 当天评分的角色岗位；
- 评分/等级/理由/风险；
- 岗位更新时间、招聘方在线时间、JD 清洗结果；
- 角色通知群配置。

## 筛选规则

1. 只取 `score_time` 为当天（Asia/Shanghai）的岗位；
2. 只取 `score >= 60` 且等级为高/中；
3. 排除关闭、重复、低置信度；
4. 招聘方超过 7 天不在线：不推；
5. 岗位更新超过 180 天：不推；
6. 每角色最多 20 条，按分数、岗位更新时间排序；
7. 当天没有合适岗位：生成“今日无合适岗位”的短日报，不硬凑。

## 日报内容

```markdown
# YYYY-MM-DD R000 角色名 日报

今日评分 N 个，符合推送标准（评分 ≥ 60）的岗位 M 个。

## 编号 公司 - 岗位
- 评分/等级
- 薪资/地点
- 岗位更新时间、招聘方在线
- 匹配理由
- JD 摘要（清洗后，最多 160 字）
- 链接
```

## 分角色与发送

- 每个角色单独生成一条 `reports` 记录；
- 发送时按角色的三个环节路由：登录/异常/日报；
- 默认通知群只作为未单独配置角色时的兜底；
- 一个角色没有合适岗位，不影响其他角色。

## 原则

- 日报是“推荐联系清单”，不是评分流水账；
- 不把系统推荐、广告、平台导航当作岗位内容；
- 评分高但招聘方长期不在线，宁可少推；
- 所有链接和岗位编号必须能回溯；
- 不泄露电话/邮箱/身份证等隐私。
