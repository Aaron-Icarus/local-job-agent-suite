# 每日搜索关键词 Skill（本地）

## 目标

根据角色画像、用户求职意愿和历史关键词效果，单独生成下一轮搜索关键词与默认兜底关键词。

**关键词不写入角色画像 MD。**

## 输入

- 角色画像（不含电话/邮箱/密码/身份证/微信/QQ）；
- 目标岗位；
- 目标城市；
- 目标薪资；
- 职业期望（高权重）；
- 相关经历；
- 历史关键词及效果：使用次数、最近使用、重复率、失败数、新增数；
- 现有推荐词和默认兜底词。

## 输出

只输出 JSON：

```json
{
  "recommended": ["AI项目经理", "AI产品经理", "AI Agent项目交付"],
  "fallback": ["AI项目经理", "AI产品经理", "智能体项目经理"]
}
```

- `recommended`：下一轮推荐，8–12 个；
- `fallback`：默认兜底，3–5 个；
- 两者不重复。

## 生成规则

1. **用户画像和求职意愿权重最高**：目标岗位、职业发展期望、城市、薪资优先；
2. 从经历拆技术/业务关键词；
3. 生成同义组合（AI项目经理 / AI项目交付 / AI产品经理 / 智能体项目经理）；
4. 城市、薪资只作为筛选条件，不写进关键词；
5. 排除过宽词（单独“项目经理”）和不相关方向；
6. 不写姓名、电话、邮箱、公司内部机密；
7. 查看历史：最近已大量搜索、重复率高、失败率高的词降低权重或轮换；
8. 保留仍能产出高匹配岗位的有效词；
9. 必须同时生成默认兜底词；
10. 控制在推荐 8–12 个、兜底 3–5 个；
11. 失败时使用本地规则兜底。

## 存放与调用

- 当前推荐/兜底：`role_keyword_entries`（`category=recommended/fallback`，`is_current=1`）；
- 兼容采集：`roles.role_keywords_json`；
- 采集器：`task_service.collectKeywords(role)` 最多读取 12 个；
- 入口：
  - 对话生成画像后自动单独生成；
  - 新建角色页“AI 生成每日关键词”按钮；
  - API `POST /api/keywords/generate`；
  - 角色维度：`GET /api/roles/:id/keywords`、`POST /api/roles/:id/keywords/generate`。
