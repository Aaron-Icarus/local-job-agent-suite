# 每日搜索关键词 Skill（本地）

## 目标

根据角色画像和目标条件，单独生成每日采集/搜索关键词。

**关键词不写入角色画像 MD，只保存到 `roles.role_keywords_json`。**

## 输入

- 角色画像（不含电话/邮箱/密码/身份证/微信/QQ）；
- 目标岗位；
- 目标城市；
- 目标薪资；
- 职业期望；
- 相关经历。

## 输出

只输出 JSON 字符串数组，8–12 个关键词，例如：

```json
["AI项目经理", "AI产品经理", "AI Agent", "智能体交付", "大模型应用", "私有化部署"]
```

## 规则

1. 从目标岗位拆主关键词；
2. 从经历拆技术/业务关键词；
3. 生成同义组合（AI项目经理 / AI项目交付 / AI产品经理 / 智能体项目经理）；
4. 城市、薪资单独作为筛选条件，不写进关键词；
5. 排除过宽词（单独“项目经理”）和不相关方向；
6. 不写姓名、电话、邮箱、公司内部机密；
7. 控制在 8–12 个；
8. 失败时使用本地规则兜底。

## 存放与调用

- 存放：`roles.role_keywords_json`；
- 采集器：`task_service.collectKeywords(role)` 取前 6 个；
- 入口：
  - 对话生成画像后自动单独生成；
  - 新建角色页“AI 生成每日关键词”按钮；
  - API `POST /api/keywords/generate`。
