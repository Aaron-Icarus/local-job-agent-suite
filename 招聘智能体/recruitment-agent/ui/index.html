  1. 打开飞书开发者后台，创建/进入自建应用。
    2. 
        
  2. 在“凭证与基础信息”复制 App ID、App Secret，填入消息页并保存。
    3. 
        
  3. 开启机器人能力，把机器人拉进目标群。
    4. 
        
  4. 群 Chat ID 以 oc_ 开头；可在群设置/开放平台接口中查看，群里发消息后事件里也会带。
    5. 
        
  5. 在“事件与回调”选择长连接，订阅 im.message.receive_v1。
    6. 
        
  6. 在“调整配置”里填群名称、Chat ID、角色和通知节点，保存后点“同步群到消息平台”。
    7. 
        
  7. 点“启动消息平台”，然后在群里 @机器人 测试；没有默认群时只记录本地通知。
