飞书机器人与群配置

      
    
        
  1. 打开飞书开发者后台，创建/进入自建应用。
    2. 
        
  2. 在“凭证与基础信息”复制 App ID、App Secret，填入消息页“飞书机器人应用”并保存。
    3. 
        
  3. 开启机器人能力，把机器人拉进目标群。
    4. 
        
  4. 群 Chat ID 以 oc_ 开头；可在群设置/开放平台接口中查看，群里发消息后事件里也会带。
    5. 
        
  5. 在“事件与回调”选择长连接，订阅 im.message.receive_v1。
    6. 
        
  6. 回到客户端“飞书群管理”，点“添加群”，填群名称、Chat ID、Webhook（可选），保存。
    7. 
        
  7. 在群卡片上点“测试”，确认群通道正常；异常群会排在最前面。
    8. 
        
  8. 点“同步群到消息平台”，让独立消息平台读取群配置；必要时重启消息平台。
    9. 
        
  9. 回到客户端点“启动消息平台”，在群里 @机器人 测试。
    10. 
        
  10. 在“默认通知群”和“角色通知群”里选择群并保存；前者是新角色默认，后者按角色/环节发送。
    11. 
      

      

      
群同步与应用配置的区别

      
“飞书群管理”负责群本身（增删改查、测试）；“同步群到消息平台”只是把已保存的群写给独立消息平台进程，不新增群；“飞书机器人应用”只负责 App ID/Secret、长连接、Webhook，不负责角色分配。

      
飞书后台操作顺序

      
    
        
  1. 创建自建应用 → 复制 App ID / App Secret。
    2. 
        
  2. 开启机器人能力 → 拉入群 → 获取群 Chat ID。
    3. 
        
  3. 事件与回调 → 长连接 → 订阅 im.message.receive_v1。
    4. 
        
  4. 回到客户端保存应用配置 → 启动消息平台。
    5. 
      

      
客户端操作顺序

      
    
        
  1. 飞书群管理 → 添加群 → 测试。
    2. 
        
  2. 同步群到消息平台（如使用独立平台进程）。
    3. 
        
  3. 默认通知群 → 选群 → 保存。
    4. 
        
  4. 角色通知群 → 每角色选择登录/异常/日报群 → 保存角色路由。
    5. 
        
  5. 在群里 @机器人 验证。
    6.
