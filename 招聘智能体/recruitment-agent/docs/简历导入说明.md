# 简历 Markdown 导入格式

项目目前没有现成的真实简历文件；`config/profile_rules.json` 只是岗位筛选规则，`docs/candidate_profile.template.md` 是空模板。  
现在支持把简历保存为 `.md` 后导入角色页面，原始 Markdown 会完整保存到 `resumes.raw_md`，本地解析结果保存到 `resumes.parsed_json`。

## 推荐结构

```markdown
# 张三简历

## 目标岗位
实施顾问、交付专员

## 技能
项目管理、客户沟通、需求调研、SQL

## 工作经历
5 年企业软件实施与项目交付经验。

## 项目经历
某企业 ERP 上线项目，负责需求调研和培训。

## 教育
本科
```

## 字段说明

| 字段 | 来源 | 说明 |
| --- | --- | --- |
| `name` | 一级标题 | 去掉“简历/个人简历” |
| `target_roles` | 目标岗位/求职意向/期望岗位 | 逗号、顿号、斜杠分隔 |
| `skills` | 技能/专业能力/技术栈 | 同上 |
| `experience_summary` | 工作经历/项目经历/经验 | 截取前 2000 字 |
| `education` | 教育/学历 | 原样保留 |
| `summary` | 个人简介/自我评价/概述/摘要 | 原样保留 |
| `sections` | 所有标题 | 标题 → 段落文本 |
| `raw_md` | 原文 | 完整保留，AI 深读可再用 |
| `content_hash` | 原文 | SHA-256，用于去重/版本 |

## 数据库

`resumes` 表：

```text
id / name / source_type / file_name / raw_md / parsed_json / content_hash / created_at / updated_at
```

角色表 `roles.resume_id` 关联简历；角色画像 `profile_md` 在创建时由简历解析生成，后续可人工/AI 调整。

## 当前限制

- 本地解析只做标题/段落抽取，不做 AI 语义理解；
- 角色确认前的 AI 深读、相似度判断仍需接入 AI Provider；
- 简历是个人隐私数据，只存本机 `data/v1.4/jobs.db`，不要提交到 GitHub。
